# Play Store listing (ASO)

Limits: title 30, short description 80, full description 4000 characters.
Google Play has no keyword field. Ranking comes from the title, the short
description and the full description, so the target keywords are worked into
those three, most important first.

Screenshots: `store/out/<lang>/screenshot-1..8.png` (1080x1920), in order.
Feature graphic: `store/out/<lang>/feature-graphic.png` (1024x500).

## English (en-US)

### Title

```
CloudFlare Mobile: DNS & WAF
```

### Short description

```
Manage Cloudflare DNS, firewall, analytics and Workers from your phone, with AI.
```

### Full description

```
CloudFlare Mobile is a fast, clean Cloudflare manager for Android. Edit DNS records, switch on Under Attack Mode, check traffic and manage Workers from your phone, without opening a laptop.

It is an unofficial client that talks directly to the official Cloudflare API with your own API token.

DNS MANAGER
• Search, filter and edit DNS records: A, AAAA, CNAME, MX, TXT and more
• Turn the Cloudflare proxy on or off with one tap
• DNS templates for common setups
• Find any zone or record with global search

SECURITY AND FIREWALL
• Under Attack Mode, Development Mode and Pause Zone on top of every zone
• Create, edit and toggle WAF custom rules
• Block, challenge or allow IP addresses and ranges
• SSL/TLS mode, Always Use HTTPS and minimum TLS version

ANALYTICS
• Requests, cached vs uncached, bandwidth and threats
• Cache hit rate at a glance
• 1 day, 7 day and 30 day views

AI ASSISTANT
• AI security audit: a score for your zone and the fixes that raise it
• Ask in plain language: "add an A record for shop pointing to 203.0.113.50"
• Every change is shown first. Nothing runs until you approve it

DEVELOPER PLATFORM
• Workers with live logs
• KV namespaces, R2 buckets and D1 databases
• Pages projects

MORE
• Email Routing, cache purge and page rules
• Account audit logs
• Multiple accounts and profiles
• Light and dark theme
• 12 languages

PRIVACY
Your API token is stored encrypted on your device and is sent only to Cloudflare. AI features send the zone configuration needed for the answer, never your token.

Purging cache at midnight, blocking an attack from the train, or fixing a DNS record before a launch: CloudFlare Mobile keeps your Cloudflare dashboard in your pocket.

CloudFlare Mobile is an independent app. It is not affiliated with, endorsed by or sponsored by Cloudflare, Inc. Cloudflare is a trademark of Cloudflare, Inc.
```

```
CloudFlare Mobile adalah aplikasi pengelola Cloudflare untuk Android yang cepat dan rapi. Ubah record DNS, nyalakan Under Attack Mode, pantau trafik, dan kelola Workers langsung dari HP, tanpa perlu buka laptop.

Ini klien tidak resmi yang terhubung langsung ke API resmi Cloudflare memakai API token milikmu sendiri.

KELOLA DNS
• Cari, filter, dan ubah record DNS: A, AAAA, CNAME, MX, TXT, dan lainnya
• Nyalakan atau matikan proxy Cloudflare sekali ketuk

• Temukan zona atau record lewat pencarian global

KEAMANAN DAN FIREWALL
• Under Attack Mode, Development Mode, dan Jeda Zona di bagian atas tiap zona
• Buat, ubah, dan aktifkan aturan WAF kustom
• Blokir, challenge, atau izinkan alamat IP dan rentang IP
• Mode SSL/TLS, Always Use HTTPS, dan versi TLS minimum

ANALITIK
• Request, cache vs non-cache, bandwidth, dan ancaman
• Cache hit rate sekilas pandang
• Tampilan 1 hari, 7 hari, dan 30 hari

ASISTEN AI
• Audit keamanan dengan AI: skor keamanan zona beserta langkah perbaikannya
• Cukup tulis dengan bahasa sehari-hari: "tambah record A untuk shop ke 203.0.113.50"
• Setiap perubahan ditampilkan dulu. Tidak ada yang dijalankan tanpa persetujuanmu

DEVELOPER PLATFORM
• Workers dengan log langsung
• KV namespace, bucket R2, dan database D1
• Proyek Pages

LAINNYA
• Email Routing, purge cache, dan page rules
• Audit log akun
• Banyak akun dan profil
• Tema terang dan gelap
• 12 bahasa, termasuk Bahasa Indonesia

PRIVASI
API token disimpan terenkripsi di perangkatmu dan hanya dikirim ke Cloudflare. Fitur AI hanya mengirim konfigurasi zona yang dibutuhkan untuk menjawab, tidak pernah token milikmu.

Purge cache tengah malam, blokir serangan dari perjalanan, atau perbaiki record DNS sebelum rilis: CloudFlare Mobile membuat dashboard Cloudflare selalu ada di genggamanmu.

CloudFlare Mobile adalah aplikasi independen, tidak berafiliasi dengan, tidak didukung, dan tidak disponsori oleh Cloudflare, Inc. Cloudflare adalah merek dagang Cloudflare, Inc.
```
